# CodeCore

A small collection of Python practice projects.

## Task Manager Login

A simple console login, built using beginner Python topics: variables,
input, if/else and `exit()`.

- Enter your name and password. The practice login is name `Izi` and
  password `Izi@123124`.
- A wrong name or password prints "Sorry you may not proceed" and the
  program stops.
- After logging in, enter your age. Ages 13 and over are welcomed back;
  anyone younger cannot proceed.
- The age must be typed as a whole number (e.g. `15`).

### Running it

```
python3 "Test code.py"
```
